# MediFind

Find medicine nearby instantly.

## Stack
- Next.js (App Router)
- TypeScript (strict)
- Supabase (Postgres + Auth)
- Tailwind CSS
- Vitest + Playwright

## Quick Start
1. Install dependencies: `pnpm install`
2. Configure environment variables in `.env.local`
3. Run development server: `pnpm dev`
